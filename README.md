# 🧠 Image Captioning with BLIP + TTS | Final Year Project  
![Python](https://img.shields.io/badge/Python-3.10-blue?logo=python&style=flat)  ![MIT License](https://img.shields.io/badge/License-MIT-green.svg)  ![Status](https://img.shields.io/badge/Status-Completed-success)

---

## 🚀 Features
- Image selection via simple GUI (Tkinter)
- BLIP-based smart image caption generation
- Real-time Text-to-Speech output (pyttsx3)
- Clean, modular, beginner-friendly code
- Completely offline and open-source

---

## 📦 Installation

> 🔧 Make sure Python 3.10+ is installed

1. Clone this repo:
```bash
git clone https://github.com/your-username/image-captioning-final-year.git
cd image-captioning-final-year
Install the required packages:
```
```bash
pip install -r requirements.txt
```
⚠️ On some systems, TTS may require pywin32:

```bash
pip install pywin32
```
